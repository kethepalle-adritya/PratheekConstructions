# Pratheek Constructions

Vite, React, and TypeScript website backed by Supabase.

## Local setup

1. Install Node.js (LTS).
2. From the project directory, run `npm install` (PowerShell may require `npm.cmd install`).
3. Copy `.env.example` to `.env.local` and set `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY` to the Supabase project URL and publishable key.
4. Run `npm run dev` (or `npm.cmd run dev` in PowerShell) and open the local URL Vite prints.

Only use the Supabase publishable key in browser code. Never put a `service_role` or secret key in a `VITE_` variable. Access control must be enforced with Supabase Row Level Security policies.

## Admin

Open `/admin/login` and sign in with an authorized Supabase account. Manage projects, enquiries, and site settings from the protected admin area. Public pages can read published project content and submit enquiries; they must not read private enquiry records.

Project images and documents use the existing `project-media` Supabase Storage bucket. Configure bucket policies for the intended public display and authenticated uploads.

## Vercel deployment

1. Import this repository into Vercel and keep the framework preset as Vite.
2. Add `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY` under Project Settings → Environment Variables for Production, Preview, and Development as needed.
3. Deploy. Vercel serves the `dist` directory generated by `npm run build`; the included `vercel.json` rewrites client-side routes to `index.html`.
4. In Supabase Auth URL Configuration, add the deployed site URL and any preview URLs you use to the allowed redirect URLs.
5. Replace the placeholder domain in `public/sitemap.xml` with the deployed canonical domain before submitting the sitemap to search engines.

## Commands

- `npm run dev` — local development server
- `npm run build` — production build
- `npm run preview` — serve the production build locally

## Project structure

- `src/pages` — public and admin pages
- `src/components` — layouts and reusable UI
- `src/lib` — Supabase client and public/admin data access
- `public` — static SEO assets
